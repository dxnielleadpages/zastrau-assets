# Zastrau Immobilien · Assets

Öffentliche Bild-, Logo-, Video- und Font-Assets für die Website von Zastrau Immobilien (Ostfriesland & Oldenburg).
Alle Bilder als WebP (lange Kante max. 2400 px). Fotos farbig und unbearbeitet.

- Basis-URL (GitHub Pages, auch für Videos): `https://dxnielleadpages.github.io/zastrau-assets/`
- CDN-Fallback für Bilder (jsDelivr, max. 20 MB pro Datei): `https://cdn.jsdelivr.net/gh/dxnielleadpages/zastrau-assets@main/`
- Vollständige Liste mit Motiv, Maßen und Einsatz: [`manifest.json`](manifest.json)

## Benennung

- `img/buero/<standort>/<standort>-<motiv>-NN.webp` · Motive: fassade, schaufenster, schild, innen, logowand, fahne, detail, menschen
- `img/team/<person>/<person>-hauptportrait.webp` · das Porträt der Live-Seite (4:5)
- `img/team/<person>/<person>-portrait-<hoch|quer|quadrat>[-sw]-NN.webp` · weitere Ausschnitte
- `img/team/freisteller/<person>-freisteller.webp` · Ganzkörper, transparent
- `img/team/gruppe/team-2026-collage.webp` · aktuelles Teamfoto (September 2026)
- `img/film/film-<motiv>.webp` · Standbilder aus dem Imagefilm
